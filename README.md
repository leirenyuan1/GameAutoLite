# 🎮 GameAutoLite — 游戏自动化助手

基于 **OpenCV 模板匹配** + **贝塞尔曲线鼠标轨迹** 的 Windows 桌面游戏自动化工具。全中文 PyQt6 图形界面，无需任何编程知识即可使用。

## ✨ 功能特性

### 核心功能
- **图像识别匹配** — 截取游戏画面，使用 OpenCV `TM_CCOEFF_NORMED` 模板匹配算法，精准识别目标图案
- **防检测鼠标轨迹** — 四阶贝塞尔曲线 + 物理惯性速度曲线 + 路径微抖动，模拟真人操作手感
- **真实按压点击** — mouseDown → 随机停留 50~150ms → mouseUp，杜绝封号风险
- **可视区域选择** — 全屏静态底图冻结 + 原色镂空高亮 + 4倍准星放大镜，HUD 实时呈现划定尺寸与绝对物理像素坐标
- **截图即上传** — 内置屏幕截图工具，Win32 DWM 硬件级帧同步零残影（~20ms 瞬发唤起），所见即所得
- **测试识别回显** — 单任务独立测试识别，屏幕真实命中位置呈现 1.2 秒穿透高亮框与置信度，纯 SVG 图标反馈
- **自定义快捷键** — 支持单键（F8）和组合键（Ctrl+Shift+P），可同时绑定多个快捷键，具备防连发与抬手防闪灰闭环状态机

### 任务管理
- **多任务队列** — 支持多个识别任务同时运行，按顺序循环扫描
- **任务独立启用开关** — 任务 Header 独立勾选框，随时启停单个任务，侧边栏具备全禁用安全拦截
- **一键复制克隆** — 支持一键深拷贝卡片完整配置，智能自增递增命名（如 `任务1(2)` → `任务1(3)`）
- **限定识别范围 (Search ROI)** — 支持局部切片扫描加速，底层透明累加物理绝对坐标，点击零偏移，大幅提升帧率
- **可折叠任务卡片** — 支持展开/折叠/排序/删除动画，550px 极窄视口 0 溢出
- **自动命名** — 新建卡片自动命名为"任务N"，重名自动校验与红框最高优先级保护
- **灵活延迟配置** — 每个任务独立设置识别后随机延迟 + 点击后冷却时间，允许合法 0ms 全速扫描
- **自定义点击次数** — 可编辑下拉框，预设单击/双击，可填入1~9999自定义次数

### 点击区域
- **单区域模式** — 拖拽框选一个点击区域
- **多区域模式** — 勾选后可连续框选多个区域，引擎按面积加权随机点击
- **跟随识别图** — 勾选后点击匹配到的位置，无需手动框选区域

### 停止条件
- **任务执行次数** — 指定任务执行 N 次后自动停止
- **运行时间限制** — 运行时间达到 N 分钟后自动停止
- **识别指定图片** — 识别到特定图片后自动停止
- **无匹配超时** — N 分钟无匹配后自动停止

### 数据看板
- **全景 KPI 指标卡** — 实时统计「运行耗时」、「匹配成功」、「累计点击」、「平均扫描耗时」，待机与运行状态无缝联动
- **双视角即时切换** — 支持「本次运行」与「历史累计」双维度数据视图切换，配置自动持久化存储（带损坏早退防覆盖保护）
- **任务匹配排行榜** — 实时统计各任务被匹配触发的独立频次（200ms 防抖刷新），直观掌握多任务负载分布
- **匹配趋势分析** — 按每 10 秒为一区间自动归总，平滑展现多任务触发频率随时间的走势变化
- **物理像素热力散点图** — 基于 Letterbox 算法等比例映射屏幕真实物理视口，物理点击落点分布一目了然
- **高清散点视口弹窗** — 支持独立弹窗与全屏最大化，8px 精确半径命中探测 + 悬浮十字准星，精准显示点击绝对坐标与触发时间点
- **执行流水审计** — 双队列解耦记录最近 50 条匹配流水（含置信度、延迟冷却、落点坐标），支持一键复制到剪贴板（智能过滤占位符）

### 悬浮窗
- **最小化时显示** — 最小化主窗口后显示悬浮状态卡片
- **始终显示** — 可选始终显示悬浮窗
- **透明度调节** — 30%~100% 可调
- **鼠标穿透** — 开启后鼠标事件穿透到下层窗口，不干扰游戏操作
- **拖拽移动** — 支持拖拽悬浮窗到任意位置

### 配置管理
- **配置自动保存** — 关闭时自动保存配置，下次启动恢复全部配置（原子写入，异常退出不损坏）
- **方案导入导出** — 将任务配置导出为 `.galt` 文件，随时导入恢复（替换/新增两种模式）
- **方案嵌入图片** — 导出时图片 Base64 嵌入 .galt 文件，导入时智能检测还原
- **停止条件随方案保存** — 方案导出包含停止条件配置与停止图片
- **停止条件导入询问** — 新增导入带停止条件的方案时，可选覆盖当前停止条件、保留或取消

### 远程监控
- **手机扫码连接** — 生成二维码，手机浏览器扫码即可连接
- **实时状态查看** — 手机端实时显示引擎运行状态
- **战绩数据同步** — 手机端实时同步展示当前「运行时长」与「匹配触发」累计次数
- **远程启停控制** — 手机端一键启停引擎
- **远程截图查看** — 手机端查看当前屏幕截图
- **局域网访问** — 无需互联网，同一 WiFi 下即可使用
- **令牌鉴权** — 服务每次启动随机生成访问令牌，二维码/链接自动携带；单独打开地址需输入令牌（桌面端「连接信息」卡显示），防止局域网内任意设备控制

### 其他
- **全局设置** — 图像扫描间隔、鼠标移动/点击速度可调（0.5X~2.0X）
- **开始后自动最小化** — 勾选后启动引擎自动最小化，停止时自动恢复
- **自动申请管理员权限** — 启动时自动请求（keyboard 全局热键需要）
- **窗口可调整大小** — 支持拖拽调整窗口大小
- **单实例运行** — 重复启动会弹出提示并退出，杜绝配置互踩、热键冲突、多引擎同时运行
- **统一线框图标** — 界面全面使用线性描边 SVG 图标（导航/状态/按钮/箭头），跟随主题色变化，风格简约统一

## 🚀 快速开始

### ⚠️ 注意

运行软件后（无论是源码运行还是打包版），首次启动会在同目录下生成：
- `config.json` — 配置文件，保存你的任务设置和全局选项
- `screenshots/` — 存放截图上传的识别模板图片

这些文件由程序自动管理，不需要手动创建。

### 方式一：直接运行（推荐）

从 [Releases](../../releases) 页面下载 `GameAutoLite-folder.zip`，解压后双击运行其中的 `GameAutoLite.exe`。

> 自 v3.4 起不再提供单文件 exe，仅提供压缩包形式（解压运行启动更快、更稳定）。

如点击无效，请右键选择「以管理员身份运行」。

### 方式二：从源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/leirenyuan1/GameAutoLite.git
cd GameAutoLite

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main.py
```

### 打包为 exe

```bash
# 文件夹形式（当前唯一发布形式，启动快）
# --noconfirm：自动覆盖已有的 dist/build，重复打包无需手动确认
python -m PyInstaller --noconfirm --windowed --icon=icon.ico --name=GameAutoLite --add-data "icon.ico;." main.py
```

打包后把 `dist/GameAutoLite/` 整个目录压缩为 `GameAutoLite-folder.zip` 发布。

## 📖 使用说明

1. **添加任务** — 点击「添加任务」，新建一张任务卡片
2. **上传识别图** — 点击「上传识别图」选择本地图片，或点击「截图上传」框选屏幕区域
3. **设定点击区域** — 点击「设定」，在游戏画面上拖拽划定要点击的位置（或多选模式框选多处）
4. **调整匹配精确度** — 滑块设置 50%~99%，越高越精确但越难匹配
5. **配置延迟** — 设置识别后的随机延迟范围（默认 200~500ms）
6. **设置停止条件**（可选） — 切换到「停止条件」页面，按需配置自动停止规则
7. **启动** — 点击绿色「开始」按钮或按 F8（可自定义），引擎开始循环扫描
8. **停止** — 点击红色「停止」按钮或按快捷键
9. **远程监控** — 切换到「远程监控」页面，手机扫码会自动携带访问令牌连接；若手动打开地址，请从桌面端「连接信息」卡输入访问令牌

> 💡 提示：如点击无效，请右键本软件选择「以管理员身份运行」

## 🔒 防检测设计

- 点击落点在目标区域内 **均匀随机取点**，绝不取中心
- 鼠标移动使用 **四阶贝塞尔曲线**，控制点有 ±120px 随机偏移产生自然弧度
- 路径叠加 **±1~2px 逐点抖动**，模拟人手微颤
- 移动耗时按距离动态分配（短距 `150~300ms`，长距 `400~650ms`）
- 点击拆分为 **按下 → 随机延迟 → 松开**，模拟真实点击停留

- **框选器重构与 Win32 DWM 硬件级帧同步零残影**：

- **任务管理能力扩充：独立开关、一键复制与限定识别范围 (ROI)**：

  - **一键复制深拷贝与自增命名**：正则剥离末尾数字括号，克隆生成 `任务1(2)`、`任务1(3)`，杜绝无脑递归累加；
  - **限定识别范围 (Search ROI)**：局部切片扫描加速，底层透明累加全屏物理绝对坐标，引擎主循环无感调用且点击零偏移；支持一键重置全屏。
- **底层引擎与输入校验工业级加固**：
  - **`mss` 截图引擎 TLS 复用与异常自愈**：线程本地实例复用大幅减少 GDI 句柄申请开销，句柄失效自动销毁并重建重试，异常时优雅回退 `pyautogui`；
  - **数字校验器（`DefaultIntValidator`）分流与失焦规整**：停止条件输入框强制正整数兜底；卡片延迟/冷却与全局扫描间隔允许合法 `0` 值（全速连续扫描），失焦自动触发 `editingFinished` 格式规整与推荐默认值回填；
  - **图像匹配得分安全闭区间钳制**：得分严格钳制在 `[0.0, 1.0]`，有限性检查杜绝 OpenCV 在极端模板下的负数或 NaN；
  - **快捷键录制闭环状态机**：过滤按键连发，引入 `_releasing_combo` 标记，支持松开主键改按新键或点击确定自动锁定最新有效组合，单按修饰键松开保留已捕获键，杜绝闪灰；
  - **Qt 浮窗防连带退出守卫**：全量工具浮窗显式声明 `WA_QuitOnClose = False`，彻底封死因主窗口临时隐藏导致关闭选区遮罩或浮窗误退主程序的 Qt 隐患。
- **数据看板历史累计重构与多网卡自适应**：
  - **历史累计双卡片精简排版**：累计点击贡献榜与数据备份指引卡片并列，空状态自适应折行，50ms 单次定时器 resizeEvent 防抖自适应与 420px 视口保底计算，550px 极窄视口 0 横向滚动条；
  - **散点大图动态虚线十字准星**：独立弹窗鼠标悬浮命中散点时，实时绘制穿过该点的全视口红色虚线十字准星与 12px 醒目外环；
  - **多网卡识别与 3 列弹性防漂移布局**：纯标准库检测支持物理 Wi-Fi（192.168.* 优先）、Tailscale 与 Mihomo TUN (198.18.*) 虚拟网卡多网卡自适应下拉；三列弹性网格彻底根治多网卡模式下主窗口横向拉伸导致的内容右移漂移。
