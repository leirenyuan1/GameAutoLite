# 🎮 GameAutoLite — 极简游戏自动化助手

基于 **OpenCV 模板匹配** + **贝塞尔曲线鼠标轨迹** 的 Windows 桌面游戏自动化工具。全中文 PyQt6 图形界面，无需任何编程知识即可使用。

## ✨ 功能特性

- **图像识别匹配** — 截取游戏画面，使用 OpenCV `TM_CCOEFF_NORMED` 模板匹配算法，精准识别目标图案
- **防检测鼠标轨迹** — 四阶贝塞尔曲线 + 物理惯性速度曲线 + 路径微抖动，模拟真人操作手感
- **真实按压点击** — mouseDown → 随机停留 50~150ms → mouseUp，杜绝封号风险
- **可视区域选择** — 半透明全屏遮罩拖拽划定点击区域，所见即所得
- **截图即上传** — 内置屏幕截图工具，直接框选游戏画面作为识别模板
- **F8 全局热键** — 游戏内一键启停，无需切换窗口
- **多任务队列** — 支持多个识别任务同时运行，按顺序循环扫描
- **灵活延迟配置** — 每个任务独立设置识别后随机延迟 + 点击后冷却时间
- **配置自动保存** — 关闭时自动保存 `config.json`，下次启动恢复全部配置

## 🛠 技术栈

| 组件 | 用途 |
|------|------|
| **PyQt6** | 图形界面框架 |
| **OpenCV + mss** | 屏幕截图与模板匹配 |
| **pywin32** | Windows API 鼠标控制 |
| **keyboard** | 全局热键注册 |

## 🚀 快速开始

### 方式一：直接运行 exe（推荐）

从 [Releases](../../releases) 页面下载 `GameAutoLite.exe`，双击运行即可。如点击无效，请右键选择「以管理员身份运行」。

### 方式二：从源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/leirenyuan1/GameAutoLite.git
cd GameAutoLite

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main_ui.py
```

### 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --add-data "config.json;." main_ui.py
```

## 📖 使用说明

1. **添加任务** — 点击「＋ 添加任务」，新建一张任务卡片
2. **上传识别图** — 点击「🖼 上传识别图」选择本地图片，或点击「📷 截图上传」框选屏幕区域
3. **设定点击区域** — 点击「⊕ 设定点击区域」，在游戏画面上拖拽划定要点击的位置
4. **调整匹配精确度** — 滑块设置 50%~99%，越高越精确但越难匹配
5. **配置延迟** — 设置识别后的随机延迟范围（默认 200~500ms）
6. **启动** — 点击绿色「▶ 开始」按钮或按 F8，引擎开始循环扫描
7. **停止** — 点击红色「⏹ 停止」按钮或按 F8

> 💡 提示：如点击无效，请右键本软件选择「以管理员身份运行」

## 🔒 防检测设计

- 点击落点在目标区域内 **均匀随机取点**，绝不取中心
- 鼠标移动使用 **四阶贝塞尔曲线**，控制点有 ±120px 随机偏移产生自然弧度
- 路径叠加 **±1~2px 逐点抖动**，模拟人手微颤
- 移动耗时按距离动态分配（短距 150~300ms，长距 400~650ms）
- 点击拆分为 **按下 → 随机延迟 → 松开**，模拟真实点击停留
